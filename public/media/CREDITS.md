Because the ambient loop is derived from a CC BY 4.0 still, the attribution for
`bkc-financial-district.jpg` covers it and is published alongside the others.

## Regenerating

```bash
npm run build:media
```

Requires `ffmpeg-static`, which is already a devDependency. The intermediate
directory `.media-tmp/` is safe to delete.

## Replacing with client photography

When Fintwiz supplies its own photography, drop the files into this directory,
update `lib/media.ts`, and remove the corresponding rows from the table above
and from the credits block on the Terms page.
